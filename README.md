# Trade2 — Trading Order Interface

A modern and responsive trading platform UI built with HTML, CSS, and JavaScript.

## Features

- Professional trading dashboard
- Buy and Sell order interface
- Asset selection
- Market Order
- Limit Order
- Stop Order
- Quantity input
- Price display
- Automatic estimated total calculation
- Available balance display
- Interactive price chart
- Chart time-range controls
- Simulated order book
- Recent orders
- Order status display
- Order confirmation notifications
- Responsive desktop and mobile design
- Demo trading environment

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas
